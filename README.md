# Brain Industries — website

Official website of Brain Industries (Pty) Ltd: https://www.brainindustriessa.co.za

A static site built with [Eleventy](https://www.11ty.dev/) and deployed to GitHub Pages.

```bash
npm install
npm start        # local preview at http://localhost:8080
npm run build    # production build into _site/
npm run check    # check internal links after a build
```

- **[HANDOVER.md](HANDOVER.md):** structure, editing content, deployment, custom domain and contact form setup.
- **[CONFIRMATION.md](CONFIRMATION.md):** content items that still need confirmation.
